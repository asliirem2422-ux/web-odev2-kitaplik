# Web Teknolojileri ve Programlama - Ödev 2 (Mini Kitaplık)

Bu proje, React, TypeScript ve Vite kullanılarak geliştirilmiş bir mini kitap arama ve favori yönetim uygulamasıdır.

## 🔗 Canlı Demo
- **Vercel Linki:** [web-odev2-kitaplik.vercel.app](web-odev2-kitaplik.vercel.app)

## 🚀 Özellikler
- **Arama Çubuğu:** Başlık ve yazara göre anlık filtreleme.
- **Kategori Filtresi:** Web, CS ve Tasarım kategorilerine göre seçim.
- **Favori Sistemi:** Kitapları favorilere ekleme ve çıkarma.
- **Veri Kalıcılığı (LocalStorage & useEffect):** Sayfa yenilendiğinde son yapılan arama ve favoriye eklenen kitaplar korunur.
- **Bileşen Mimarisi:** Controlled components ve Lifting State Up prensipleriyle geliştirilmiştir.

## 🛠️ Kullanılan Teknolojiler
- React (Hooks: useState, useEffect)
- TypeScript
- Vite
- CSS3
